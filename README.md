# Deepfake detection

With ever improving generative models for images and video, humans often fail to recognize whether an image is fake or real. 

Can AI systems be a tutor where humans can learn from?

Here we present work that can be used to help humans learn from AI. We have used a *visual reasoning model* to give arguments why an image can be real or fake. 
Based on the quality of the output of the model, most humans (those without specialized training in recognizing deepfakes) can learn from the arguments provided by the reasoning model.

The notebook presents both arguments for and against whether an image is fake or real.
